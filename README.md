One painfully honest out-of-office auto-reply for make.fun's "The Painfully Honest Out-of-Office" bounty. `main.py` writes a single 146-character reply to `entry.txt`: a warm thank-you, then the confession that the sender will reply on return just as soon as the inbox has been cleared by deleting everything too polite to delete.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
